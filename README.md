# keenetic-doq-web

Веб-интерфейс для [keenetic-doq](https://github.com/necronicle/keenetic-doq)

## Установка

curl -fsSL https://raw.githubusercontent.com/accept4/keenetic-doq-web/main/install.sh | tr -d '\r' | sh
## Удаление

curl -fsSL https://raw.githubusercontent.com/accept4/keenetic-doq-web/main/uninstall.sh | tr -d '\r' | sh

Открыть: http://IP-роутера:8088
